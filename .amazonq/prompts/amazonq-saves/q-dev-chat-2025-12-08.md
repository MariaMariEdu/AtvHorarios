Implementação completa da funcionalidade de **Consultas de Aulas** no mobile:

## Arquivos Criados

1. **ConsultasScreen.js** - Tela principal com grade visual de horários
2. **CONSULTAS_MOBILE.md** - Documentação completa da funcionalidade
3. **App.js** - Atualizado com nova aba de Consultas
4. **README.md** - Atualizado com as novas funcionalidades

## Funcionalidades Implementadas

### Grade Visual de Horários
- Layout em grade com dias da semana (colunas) e horários (linhas)
- Scroll horizontal e vertical para navegação completa
- Cards coloridos para cada disciplina (8 cores diferentes)
- Informações exibidas: disciplina, professor, curso e horário

### Filtros de Consulta
- **Laboratório**: Filtra aulas por laboratório específico
- **Curso**: Filtra aulas por curso
- **Disciplina**: Filtra aulas por disciplina
- **Professor**: Filtra aulas por professor
- **Limpar Filtros**: Remove todos os filtros

### Organização dos Dados
- Dias da semana: Segunda a Sábado
- Blocos ordenados por horário de início
- Estrutura de grade: `grade[dia][blocoId] = aula`
- Normalização automática de IDs para nomes legíveis

### Integração com API
- Utiliza endpoint `GET /api/v1/aulas` com query params
- Carrega dados de cursos, disciplinas, professores, laboratórios e blocos
- Tratamento de erros com mensagens em português

### Componentes Visuais
- Header roxo (#6200ee) com dias da semana
- Células de horário (80px) e aulas (120px x 80px)
- Cards com elevação e cores diferenciadas
- Snackbar para feedback de operações

A tela está integrada ao navegador principal com ícone "calendar-search" e título "Consultas".
