## Modelo Mongoose para Aulas

O modelo `Aula` foi criado com sucesso no arquivo `projeto/backend/src/models/Aula.js` com as seguintes características:

### Campos do Schema

- **`semestre`**: String obrigatória para o semestre letivo (ex: '2025/1')
- **`cursoId`**: ObjectId obrigatório referenciando o modelo Curso
- **`disciplinaId`**: ObjectId obrigatório referenciando o modelo Disciplina  
- **`professorId`**: ObjectId obrigatório referenciando o modelo Professor
- **`laboratorioId`**: ObjectId obrigatório referenciando o modelo Laboratorio
- **`diaSemana`**: String obrigatória com enum dos dias da semana
- **`blocos`**: Array de ObjectIds referenciando BlocoHorario
- **`dataInicio`**: Date obrigatória para início da vigência
- **`dataFim`**: Date obrigatória para fim da vigência (com validação para ser posterior à data de início)

### Validações Implementadas

- Todos os campos obrigatórios têm mensagens de erro personalizadas
- Enum para dias da semana com valores válidos
- Validação customizada para garantir que `dataFim` seja posterior a `dataInicio`
- Timestamps automáticos (`createdAt` e `updatedAt`)

### Documentação JSDoc

- Documentação completa de todos os campos
- Tipos TypeScript definidos
- Exemplos de uso
- Referências aos modelos relacionados
- Descrições detalhadas de cada propriedade

## CRUD de Aulas - Implementação Completa

### Endpoints REST Implementados

#### **POST /api/v1/aulas**
- Cria nova aula com validação de conflitos
- Verifica conflitos de laboratório e professor no mesmo dia/horário
- Retorna `400` com detalhes do conflito se houver sobreposição

#### **GET /api/v1/aulas**
- Lista aulas com filtros opcionais:
  - `cursoId`, `professorId`, `disciplinaId`, `semestre`, `diaSemana`
  - Paginação: `page` e `limit`
- Popula dados relacionados (curso, disciplina, professor, laboratório, blocos)

#### **GET /api/v1/aulas/:id**
- Busca aula específica por ID
- Retorna `404` se não encontrada

#### **PUT /api/v1/aulas/:id**
- Atualiza aula com validação de conflitos
- Exclui a própria aula da verificação de conflitos
- Retorna `404` se aula não existir

#### **DELETE /api/v1/aulas/:id**
- Remove aula por ID
- Retorna `204` em sucesso, `404` se não encontrada

### Validações de Conflito Implementadas

#### **Conflito de Laboratório**
- Impede mesmo laboratório no mesmo dia/blocos de horário

#### **Conflito de Professor**
- Impede mesmo professor no mesmo dia/blocos de horário

#### **Formato de Erro de Conflito**
```json
{
  "message": "Conflito de horário",
  "details": {
    "tipo": "laboratorio|professor",
    "diaSemana": "Segunda",
    "blocos": ["idDoBloco"]
  }
}
```
